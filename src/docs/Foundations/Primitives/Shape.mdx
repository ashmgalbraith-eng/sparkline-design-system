# Shape

Border radius tokens define the corner rounding used across all components.

<div style={{ display: 'flex', flexWrap: 'wrap', gap: '24px', marginTop: '32px', marginBottom: '32px' }}>

    { token: 'radius-sm', value: '2px', label: 'sm' },

    { token: 'radius-xl', value: '12px', label: 'xl' },
    { token: 'radius-full', value: '999px', label: 'full' },
  ].map(({ token, value, label }) => (
    <div key={token} style={{ display: 'flex', flexDirection: 'column', alignItems: 'center', gap: '12px' }}>
      <div style={{

        height: '80px',
        background: '#783EF9',
        borderRadius: value,
      }} />
      <span style={{ fontFamily: 'Roboto, sans-serif', fontWeight: 700, fontSize: '13px', color: '#000' }}>{token}</span>
      <span style={{ fontFamily: 'Roboto, sans-serif', fontSize: '12px', color: '#757575' }}>{value}</span>
    </div>
  ))}
</div>

## Token Reference

| Token | Value | Usage |
|---|---|---|
| `$radius-sm` | 2px | Subtle rounding — badges, tags |
| `$radius-md` | 4px | Default rounding — inputs, buttons |
| `$radius-lg` | 8px | Cards, modals, panels |
| `$radius-xl` | 12px | Large cards, sheets |
| `$radius-full` | 999px | Pills, chips, switches, avatars |

## Implementation

```css
.badge        { border-radius: var(--radius-sm); }
.button       { border-radius: var(--radius-md); }
.card         { border-radius: var(--radius-lg); }
.sheet        { border-radius: var(--radius-xl); }
.chip         { border-radius: var(--radius-full); }
```
