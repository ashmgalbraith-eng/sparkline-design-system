# Typography Tokens

Semantic typography tokens compose [primitive values](?path=/docs/foundations-primitives-typography--docs) into named, purposeful styles used by components. Each token maps directly to a Figma text style.

Responsive styles (Display, Headline 1–3) have breakpoint variants at `lg`, `md`, and `sm`. Styles that don't change across breakpoints are defined once.

## Token Reference

Token keys match Figma text style names and are exported from `typographyTokens` in `src/tokens/tokens.ts`.

### Responsive tokens (nested `lg / md / sm`)

```ts
import { typographyTokens } from '@sparkline/design-system';

// Access a specific breakpoint variant:
typographyTokens.display.lg
// → { fontFamily: 'Roboto', fontSize: '56px', fontWeight: 800, lineHeight: '100%', letterSpacing: '0' }

typographyTokens['headline-1'].md
// → { fontFamily: 'Roboto', fontSize: '40px', fontWeight: 700, lineHeight: '115%', letterSpacing: '-1px' }
```

| Token key | lg | md | sm |
|---|---|---|---|
| `display` | 56px / 800 / 100% | 48px / 800 / 110% | 40px / 800 / 115% |
| `headline-1` | 48px / 700 / 100% | 40px / 700 / 115% / -1px | 32px / 700 / 120% / -0.5px |
| `headline-2` | 40px / 700 / 100% | 32px / 700 / 120% / -0.5px | 24px / 700 / 125% |
| `headline-3` | 32px / 700 / 100% | 24px / 700 / 100% | 20px / 700 / 100% |

### Static tokens (flat object)

```ts
typographyTokens['headline-4']
// → { fontFamily: 'Roboto', fontSize: '20px', fontWeight: 700, lineHeight: '100%', letterSpacing: '0' }

typographyTokens['body-1']
// → { fontFamily: 'Roboto', fontSize: '16px', fontWeight: 400, lineHeight: '24px', letterSpacing: '0' }
```

| Token key | fontSize | fontWeight | lineHeight | letterSpacing |
|---|---|---|---|---|
| `headline-4` | 20px | 700 | 100% | 0 |
| `subtitle-1` | 18px | 700 | 100% | 0 |
| `label` | 16px | 700 | 100% | 0 |
| `body-1` | 16px | 400 | 24px | 0 |
| `body-2` | 14px | 400 | 20px | 0 |
| `caption` | 12px | 400 | 100% | 0 |
| `button` | 16px | 700 | 100% | 0 |

## Usage Guidelines

| Style | Use for |
|---|---|
| **Display** | Hero sections, marketing headlines |
| **Headline 1** | Page titles |
| **Headline 2** | Section headings |
| **Headline 3** | Card titles, subsection headings |
| **Headline 4** | Group labels, sidebar headings |
| **Subtitle 1** | Supporting text beneath headings |
| **Label** | Form labels, table headers |
| **Body 1** | Primary body copy, paragraphs |
| **Body 2** | Secondary body copy, helper text |
| **Caption** | Timestamps, metadata, fine print |
| **Button** | Button labels, CTAs |

## CSS Implementation

Apply responsive type using CSS custom properties. The `lg` values are the default; `md` and `sm` override at their respective breakpoints.

```css
/* Default (lg — desktop >1024px) */
:root {
  --type-display:    800 3.5rem/100%  'Roboto', sans-serif;
  --type-headline-1: 700 3rem/100%    'Roboto', sans-serif;
  --type-headline-2: 700 2.5rem/100%  'Roboto', sans-serif;
  --type-headline-3: 700 2rem/100%    'Roboto', sans-serif;

  /* Static — same across all breakpoints */
  --type-headline-4: 700 1.25rem/100% 'Roboto', sans-serif;
  --type-subtitle-1: 700 1.125rem/100% 'Roboto', sans-serif;
  --type-label:      700 1rem/100%    'Roboto', sans-serif;
  --type-body-1:     400 1rem/24px    'Roboto', sans-serif;
  --type-body-2:     400 0.875rem/20px 'Roboto', sans-serif;
  --type-caption:    400 0.75rem/100% 'Roboto', sans-serif;
  --type-button:     700 1rem/100%    'Roboto', sans-serif;
}

/* md — tablet (768px–1024px) */
@media (max-width: 1024px) {
  :root {
    --type-display:    800 3rem/110%     'Roboto', sans-serif;
    --type-headline-1: 700 2.5rem/115%   'Roboto', sans-serif;
    --type-headline-2: 700 2rem/120%     'Roboto', sans-serif;
    --type-headline-3: 700 1.5rem/100%   'Roboto', sans-serif;
  }
}

/* sm — mobile (<768px) */
@media (max-width: 768px) {
  :root {
    --type-display:    800 2.5rem/115%   'Roboto', sans-serif;
    --type-headline-1: 700 2rem/120%     'Roboto', sans-serif;
    --type-headline-2: 700 1.5rem/125%   'Roboto', sans-serif;
    --type-headline-3: 700 1.25rem/100%  'Roboto', sans-serif;
  }
}
```

```css
/* Usage */
.page-title {
  font: var(--type-headline-1);
}

.hero-headline {
  font: var(--type-display);
}

.body-copy {
  font: var(--type-body-1);
}
```
