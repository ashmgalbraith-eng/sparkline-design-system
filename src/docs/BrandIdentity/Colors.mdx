## Usage Guidelines

### Token Selection

**For Backgrounds:**
- Light: `$primary-10`, `$secondary-10`, `$neutral-10`, `$neutral-20`
- Medium: `$primary-20`, `$secondary-20`, `$neutral-30`
- Dark: `$neutral-80`, `$neutral-90`

**For Text:**
- Primary text: `$neutral-90`, `$neutral-70`
- Secondary text: `$neutral-60`, `$neutral-50`
- Disabled text: `$neutral-40`
- On dark backgrounds: `$neutral-10`

**For Interactive Elements:**
- Default: `$primary-50`
- Hover: `$primary-40`
- Active: `$primary-60`
- Focus: `$primary-50` with shadow

**For Semantic Feedback:**
- Information: `$alert-info`
- Success: `$alert-success`
- Warning: `$alert-warning`
- Error: `$alert-error`

## Implementation

### CSS
```css
.button-primary {
  background-color: var(--primary-50);
  color: var(--neutral-10);
}

.button-primary:hover {
  background-color: var(--primary-40);
}

.text-secondary {
  color: var(--neutral-50);
}

.badge-success {
  background-color: var(--alert-success);
  color: var(--neutral-10);
}
```

### JavaScript/TypeScript
```typescript
import { colors } from './tokens';

const styles = {
  backgroundColor: colors['primary-50'],
  color: colors['neutral-10'],
  borderColor: colors['neutral-30'],
};
```

## Accessibility

All color combinations meet WCAG AA standards:
- **Normal text (16px)**: Minimum 4.5:1 contrast ratio
- **Large text (18px+)**: Minimum 3:1 contrast ratio

- `$primary-50` on `$neutral-10` ✓
- `$neutral-90` on `$neutral-10` ✓
- `$neutral-10` on `$primary-50` ✓
- `$alert-error` on `$neutral-10` ✓
- `$neutral-50` on `$neutral-10` ✓
