# Typography

The Sparkline type system uses **Roboto** as the primary typeface across all components and applications. The type scale is designed to be readable, accessible, and responsive across breakpoints.

## Type Scale

The type scale adapts across three breakpoints: **Desktop** (large), **Tablet** (medium), and **Mobile** (small). Heading styles reduce in size at smaller breakpoints for readability, while body text and UI elements remain consistent.

## Usage Guidelines

### Responsive Behavior

The type scale uses three breakpoints that map to device categories:

| Breakpoint | Label | Applies to |
|---|---|---|
| **Large** | Desktop | Screens wider than 1024px |
| **Medium** | Tablet | Screens between 768px and 1024px |
| **Small** | Mobile | Screens narrower than 768px |

Heading styles (Display through Headline 3) scale down at smaller breakpoints to maintain readability and proportion. Body text, labels, and UI elements remain constant across all breakpoints.

### When to Use Each Style

| Style | Use for |
|---|---|
| **Display** | Hero sections, marketing headlines |
| **Headline 1** | Page titles |
| **Headline 2** | Section headings |
| **Headline 3** | Card titles, subsection headings |
| **Headline 4** | Group labels, sidebar headings |
| **Subtitle 1** | Supporting text beneath headings |
| **Label** | Form labels, table headers |
| **Body 1** | Primary body copy, paragraphs |
| **Body 2** | Secondary body copy, helper text |
| **Caption** | Timestamps, metadata, fine print |
| **Button** | Button labels, CTAs |

### Implementation

```css
/* Responsive type scale using CSS custom properties */
:root {
  --type-display: 800 3.5rem/100% 'Roboto', sans-serif;
  --type-h1: 700 3rem/100% 'Roboto', sans-serif;
  --type-h2: 700 2.5rem/100% 'Roboto', sans-serif;
  --type-h3: 700 2rem/100% 'Roboto', sans-serif;
}

/* Tablet */
@media (max-width: 1024px) {
  :root {
    --type-display: 800 3rem/110% 'Roboto', sans-serif;
    --type-h1: 700 2.5rem/115% 'Roboto', sans-serif;
    --type-h2: 700 2rem/120% 'Roboto', sans-serif;
    --type-h3: 700 1.5rem/100% 'Roboto', sans-serif;
  }
}

/* Mobile */
@media (max-width: 768px) {
  :root {
    --type-display: 800 2.5rem/115% 'Roboto', sans-serif;
    --type-h1: 700 2rem/120% 'Roboto', sans-serif;
    --type-h2: 700 1.5rem/125% 'Roboto', sans-serif;
    --type-h3: 700 1.25rem/100% 'Roboto', sans-serif;
  }
}
```
