# Typography Primitives

Primitive typography values are the raw, nameless building blocks of the type system — font families, weights, and sizes with no usage context attached. These are the values Figma exposes in the variable panel.

Semantic decisions (which style to use for a headline, how type scales across breakpoints) live in [Foundations/Tokens/Typography](?path=/docs/foundations-tokens-typography--docs).
