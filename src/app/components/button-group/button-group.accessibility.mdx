# Accessibility

## Role and ARIA

Button Group implements the [Toolbar pattern](https://www.w3.org/WAI/ARIA/apg/patterns/toolbar/) from the WAI-ARIA Authoring Practices. Wrap the component in a `role="toolbar"` container and provide an `aria-label` describing the group's purpose, e.g. `aria-label="Text alignment"`.

Each individual button should convey its selected state. When `showLabel` is `false` (icon-only), add `aria-label` to each item's markup or provide a tooltip so the purpose of each button is clear.

The active button should carry `aria-pressed="true"` or be represented within a `role="radiogroup"` / `role="radio"` pattern if selection is mutually exclusive (one active at a time).
