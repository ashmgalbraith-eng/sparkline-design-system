# Button Group

Button groups present a set of segmented actions in a connected row, where exactly one option is active at a time. Use them for view toggles, filter selections, or segmented controls.

<Canvas of={ButtonGroupStories.Playground} />

## Usage guidelines

<Callout>
Keep group labels short and parallel. The active item should reflect the current state, not a desired action. Limit groups to 2–5 buttons; more options are better served by a select or tab component.
</Callout>
