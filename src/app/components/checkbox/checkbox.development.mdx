# Checkbox

Checkbox manages checked/indeterminate state transitions and interaction states internally via host bindings.

## Import

<CodeBlock>{`import { CheckboxComponent } from 'sparkline-ds';

@Component({
  standalone: true,
  imports: [CheckboxComponent],
  template: '<sp-checkbox label="Email me updates" [checked]="subscribed" (checkedChange)="subscribed = $event"></sp-checkbox>',
})`}</CodeBlock>
