# Accessibility

## Role and ARIA

The host element uses `role="checkbox"` and keeps its ARIA attributes in sync automatically:

- `aria-checked="true"` when checked, `aria-checked="false"` when unchecked, and `aria-checked="mixed"` when indeterminate.
- `aria-disabled="true"` when `disabled` is `true`.
- `tabindex="0"` when enabled; `tabindex="-1"` when disabled.

Group related checkboxes inside a `<fieldset>` with a `<legend>` so the group label is announced before individual checkbox labels.

## Keyboard navigation

| Key | Behaviour |
|-----|-----------|
| `Tab` | Moves focus to the checkbox (skipped when disabled). |
| `Space` | Toggles the checked state. An indeterminate checkbox becomes checked on first `Space` press. |
