# Checkbox

Checkboxes let users select one or more items from a set. They also support an **indeterminate** state for parent checkboxes that control a partially-selected group.

<Canvas of={CheckboxStories.Playground} />

## Usage guidelines

<Callout>
Use checkboxes when users need to select multiple options or toggle a single setting that requires a save action. For binary, immediate settings, prefer a Switch. Always provide a visible label.
</Callout>
