# Input

Input implements Angular's ControlValueAccessor, so it works directly with ngModel and reactive forms in addition to its own valueChange output.

## Import

<CodeBlock>{`import { InputComponent } from 'sparkline-ds';
import { FormsModule } from '@angular/forms';

@Component({
  standalone: true,
  imports: [InputComponent, FormsModule],
  template: '<sp-input label="Email" [(ngModel)]="email" [state]="emailError ? 'error' : 'default'" [errorText]="emailError"></sp-input>',
})`}</CodeBlock>
