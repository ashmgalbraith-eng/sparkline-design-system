# Slider

Slider wraps a native `<input type="range">` and recalculates its fill percentage whenever value, min, or max change via ngOnChanges.

## Import

<CodeBlock>{`import { SliderComponent } from 'sparkline-ds';

@Component({
  standalone: true,
  imports: [SliderComponent],
  template: '<sp-slider [min]="0" [max]="100" [step]="5" [(value)]="volume" [showValue]="true"></sp-slider>',
})`}</CodeBlock>
