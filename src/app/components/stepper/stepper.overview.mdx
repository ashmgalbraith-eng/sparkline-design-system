# Stepper

Steppers guide users through a multi-step process by showing their progress. Completed steps show a check icon, the active step is highlighted, and upcoming steps appear muted.

<Canvas of={StepperStories.Playground} />

## Usage guidelines

<Callout>
Use steppers for linear processes of 3–6 steps (e.g. onboarding, checkout). Label each step concisely. Provide an optional description for added context. Use the error state to surface problems that require attention before moving forward.
</Callout>
