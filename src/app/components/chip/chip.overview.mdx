# Chip

Chips are compact, interactive elements used to represent attributes, filters, or selections. The clearable variant includes a remove action; the plain variant is static.

<Canvas of={ChipStories.Playground} />

## Usage guidelines

Use chips to show applied filters, tags, or multi-select values. The clearable variant should be used whenever the user can remove the chip. Keep chip labels short and specific — one to three words.
