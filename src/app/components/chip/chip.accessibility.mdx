# Accessibility

## Role and ARIA

Chip does not carry an implicit ARIA role. The appropriate role depends on usage:

- **Filter chip** (toggles a filter on/off) — add `role="checkbox"` and `aria-checked` to the host, or group chips in a `role="group"` with individual `aria-pressed` attributes.
- **Input chip** (represents a value in a field, e.g. multi-select tag) — expose each chip as part of a labelled region and announce additions/removals via an `aria-live` region.
- **Clearable chip** — the remove button should have `aria-label="Remove [chip label]"` so its purpose is clear to screen reader users.

`aria-disabled="true"` and `tabindex="-1"` are applied automatically when `state` is `'disabled'`.
