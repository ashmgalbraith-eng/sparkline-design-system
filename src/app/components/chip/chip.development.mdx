# Chip

Chip manages its own interaction state internally. The clearable type always shows a right icon as a remove action regardless of showRightIcon.

## Import

<CodeBlock>{`import { ChipComponent } from 'sparkline-ds';

@Component({
  standalone: true,
  imports: [ChipComponent],
  template: '<sp-chip type="clearable" label="Active filters" (removed)="clearFilter()"></sp-chip>',
})`}</CodeBlock>
