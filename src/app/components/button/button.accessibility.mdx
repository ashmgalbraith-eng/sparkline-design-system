# Accessibility

## Role and ARIA

The button host element uses `role="button"` and manages its own focus and disabled state:

- `tabindex="0"` when enabled; `tabindex="-1"` when `state` is `'disabled'`.
- `aria-disabled="true"` is applied when disabled — the element remains in the DOM and is discoverable by screen readers, but click events are suppressed.

When `showText` is `false` (icon-only), the visible label is hidden. Add an `aria-label` attribute to the host to provide a text alternative for assistive technology, e.g. `<sp-button [showText]="false" aria-label="Search" ...>`.
