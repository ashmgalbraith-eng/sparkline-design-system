# Button

Button manages its own interaction state (hover, pressed, focus) internally via host listeners, so consumers only need to bind label, type, size, and state.

## Import

<CodeBlock>{`import { ButtonComponent } from 'sparkline-ds';

@Component({
  standalone: true,
  imports: [ButtonComponent],
  template: '<sp-button type="filled" size="large" label="Save changes" (buttonClick)="onSave()"></sp-button>',
})`}</CodeBlock>
