# Card

Card is a pure layout container with no internal logic. Content is projected via ng-content.

## Import

<CodeBlock>{`import { CardComponent } from 'sparkline-ds';

@Component({
  standalone: true,
  imports: [CardComponent],
  template: '<sp-card variant="outlined" padding="lg"><h3>Account summary</h3></sp-card>',
})`}</CodeBlock>

No internal component dependencies.
