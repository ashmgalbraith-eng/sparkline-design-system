# Accessibility

## Role and ARIA

Card is a layout container with no implicit ARIA role. The appropriate semantics depend on the content and context:

- If the card represents a self-contained piece of content (e.g. an article preview), wrap projected content in `<article>` or add `role="article"` to the card itself and a heading as the first child.
- If the card is interactive (e.g. clickable to navigate), add `role="button"` or make the entire card a focusable `<a>` element with a descriptive `aria-label`.
- If the card is purely structural, no additional ARIA is needed — let the projected content carry its own semantics.

## Keyboard navigation

Card itself is not focusable. Any interactive elements inside (buttons, links) follow standard keyboard behaviour. If the entire card is interactive, ensure it receives focus via `tabindex="0"` and responds to `Enter` / `Space`.
