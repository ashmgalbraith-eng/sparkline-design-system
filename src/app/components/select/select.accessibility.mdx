# Accessibility

## Role and ARIA

Select follows the [Combobox pattern](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/) from the WAI-ARIA Authoring Practices. The trigger element should carry:

- `role="combobox"` with `aria-expanded` reflecting the open/closed state.
- `aria-haspopup="listbox"` to indicate the popup type.
- `aria-controls` pointing to the dropdown list element.

The dropdown list should have `role="listbox"`, and each option should have `role="option"` with `aria-selected` set appropriately. Disabled options should have `aria-disabled="true"`.

The visible `label` is linked to the trigger; always supply a label so screen readers announce the field's purpose when it receives focus.

In multi-select mode, each chip includes a remove button — provide `aria-label="Remove [option label]"` on each remove action.

The dropdown closes on outside click and `Escape`.
