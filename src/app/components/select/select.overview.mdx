# Select

Select fields let users choose one or more options from a dropdown list. The **multi-select** variant displays selected values as dismissible chips inside the trigger.

<Canvas of={SelectStories.Playground} />

## Usage guidelines

<Callout>
Use a select when there are five or more options. For fewer options, consider radio buttons or a button group. Always provide a `placeholder` to indicate the expected input. In multi-select mode, display selected chips clearly so users can review and remove selections.
</Callout>
