# Select

Select implements its own open/close and outside-click handling via HostListener, and supports both single and multi-select modes through the same value and valueChange API.

## Import

<CodeBlock>{`import { SelectComponent } from 'sparkline-ds';

@Component({
  standalone: true,
  imports: [SelectComponent],
  template: '<sp-select label="Account type" [options]="accountTypes" [(value)]="selectedType"></sp-select>',
})`}</CodeBlock>
