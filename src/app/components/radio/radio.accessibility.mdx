# Accessibility

## Role and ARIA

The host element uses `role="radio"` with the following attributes managed automatically:

- `aria-checked="true"` when selected, `aria-checked="false"` when not selected.
- `aria-disabled="true"` when `disabled` is `true`.
- `tabindex="0"` when enabled; `tabindex="-1"` when disabled.

Always group radio buttons inside a `<fieldset>` and `<legend>` (or `role="radiogroup"` with `aria-labelledby`) so assistive technology announces the group label before individual options.
