# Radio

Radio manages a single option's checked and interaction state. Grouping and mutual exclusivity must be implemented by the consumer (e.g. binding all options in a group to the same model value).

## Import

<CodeBlock>{`import { RadioComponent } from 'sparkline-ds';

@Component({
  standalone: true,
  imports: [RadioComponent],
  template: '<sp-radio label="Email" [checked]="contactMethod === 'email'" (checkedChange)="contactMethod = 'email'"></sp-radio>',
})`}</CodeBlock>
