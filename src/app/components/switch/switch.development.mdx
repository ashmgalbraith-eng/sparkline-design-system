# Switch

Switch is the lightest-weight stateful component in the library, with no external dependencies.

## Import

<CodeBlock>{`import { SwitchComponent } from 'sparkline-ds';

@Component({
  standalone: true,
  imports: [SwitchComponent],
  template: '<sp-switch [checked]="notificationsEnabled" (checkedChange)="notificationsEnabled = $event"></sp-switch>',
})`}</CodeBlock>

## Properties

]} />
