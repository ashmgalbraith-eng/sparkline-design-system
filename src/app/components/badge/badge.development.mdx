# Badge

Badge is a small, self-contained status indicator. It has no external dependencies and is also composed inside Avatar.

## Import

<CodeBlock>{`import { BadgeComponent } from 'sparkline-ds';

@Component({
  standalone: true,
  imports: [BadgeComponent],
  template: '<sp-badge type="numeric" status="error" label="3"></sp-badge>',
})`}</CodeBlock>
