# Badge

Badges are small status indicators that communicate counts, notifications, or semantic state. They appear attached to other UI elements such as avatars, icons, or navigation items.

<Canvas of={BadgeStories.Playground} />

## Usage guidelines

<Callout>
Use numeric badges to show counts (e.g. unread items). Use the dot variant when presence or status needs to be communicated without a count. Status color conveys meaning — use consistently across the product.
</Callout>
