# Avatar

Avatars represent a user or entity. They can display initials, an icon, or a profile image, and support notification counts and status indicators.

<Canvas of={AvatarStories.Playground} />

## Usage guidelines

<Callout>
Use the text variant with initials when no image is available. Reserve notification badges for contexts where counts are meaningful (e.g. unread messages). Status indicators communicate presence or availability.
</Callout>
